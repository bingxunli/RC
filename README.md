# RC-GWAS — remnant cholesterol meta-analysis and effector-gene prioritisation

Code for a two-cohort genome-wide meta-analysis of **remnant cholesterol (RC)** and
the downstream multi-omics prioritisation of effector genes.

* meta-analysis — Karjalainen et al. (Nature 2024) + Zoodsma et al. (Nat Genet 2025),
  N = 570,662, GRCh37
* fine-mapping — SuSiE-RSS per locus
* locus definition & annotation — FUMA / MAGMA / ANNOVAR
* effector-gene prioritisation — PoPS 0.2, FLAMES 1.1.2 (patched)
* integration — SMR 1.03, coloc, GTEx v8 eQTL, eQTLGen, deCODE pQTL, PheWAS-MR

**Headline numbers** (see `docs/NUMBERS.md` for the full table with provenance):
11,071,938 variants · 19,414 at P < 5×10⁻⁸ · 125 lead SNPs · 112 FUMA loci ·
497 high-confidence variants · 400 MAGMA genes · 73 FLAMES effector genes ·
36 SMR gene–RC associations (21 colocalised) · 21 causal PheWAS traits.

## Quick start

```bash
git clone <this repo> && cd RC-GWAS

bash env/setup_wsl.sh          # python venv + PoPS source (Linux / WSL2)
Rscript env/R_packages.R       # R packages (R 4.4.0)

less docs/PIPELINE.md          # every command, in order
```

`docs/PIPELINE.md` is the operational record: it gives the exact command for each
stage, in the order it was run. `docs/PITFALLS.md` is the list of things that will
bite you if you skip it — read at least §1 (genome build) and §2 (the SE formula)
before touching the data.

## Data (not included)

| Accession | Study | N | Notes |
|---|---|---|---|
| `GCST90302074` | Karjalainen MK et al., Nature 2024 (PMID 38448586) | 136,016 | 4,435 East Asian + 11,340 South Asian + 120,241 European; 33 cohorts, no UK Biobank |
| `GCST90499341` | Zoodsma M et al., Nat Genet 2025 (PMID 41044249) | 434,646 | UK Biobank, British ancestry |

Both from the GWAS Catalog FTP (harmonised summary statistics). UK Biobank
individual-level data are not redistributed here.

**Genome build — read before touching the data-prep code.** The pipeline runs on
**GRCh37** end to end. In `GCST90302074` the `variant_id` column is GRCh37 while
`base_pair_location` is GRCh38; the pipeline deliberately uses `variant_id`.
Switching either file to GRCh38 positions without lifting the other shifts loci by
tens to hundreds of kb. Details in `docs/PITFALLS.md` §1.

Reference panel: 1000 Genomes phase 3 EUR, GRCh37.

## Status

The gene-prioritisation layer (MAGMA / PoPS / FLAMES) has been **verified end to
end** — see `docs/PoPS_MAGMA_FLAMES_rerun.md`. None of the three reads β/SE, so the
SE-formula defect documented in `docs/PITFALLS.md` §2 does not affect them; the
re-run was a validation, not a repair, and it reproduces the published results
(PoPS Pearson r = 0.997, identical RidgeCV α; FLAMES changes one nomination).

**Still open before the meta-analysis numbers are final:** the per-cohort
genomic-control step described in `docs/PITFALLS.md` §3 is not present in any
delivered script, so `METAANALYSIS2.TBL` cannot be regenerated byte-for-byte.
`code/01_data_prep/metal_rc.txt` is provided so the run can be repeated once that
step is restored.
